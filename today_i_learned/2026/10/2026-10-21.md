# 2026-10-21

## 오늘의 기록

CCRecorder의 다음 단계를 두 갈래로 정리했다. v2.0.0에서는 iPhone·iPad 적응형 UI와 기기 간 동기화를 목표로 마일스톤과 이슈 #79~#90을 구성했고, v1.3.0에서는 화면 구조와 명명을 다듬고 SwiftData·FocusState 환경을 포함한 프리뷰를 보강했다. 재생 시간 표현은 공용 `PlaybackTimeFormatStyle`로 모아 경계와 반올림 정책을 한곳에서 관리하도록 했다.

`marcorable-kit`에는 SwiftUI 화면 구조, 하위 ViewModel 생명주기, presentation 상태, Environment 프리뷰 등의 규칙을 보완해 PR #3을 만들었다. 별도로 ReturnTheFavor 개발을 준비하기 위한 8주 React Native 학습 로드맵도 작성했다.

## 작업 기록

### 완료

- CCRecorder v2.0.0 마일스톤과 기반·화면·CloudKit·파일 동기화·멀티윈도우·접근성·회귀 테스트 이슈 #79~#90을 만들었다.
- 녹음 메타데이터와 파일 동기화를 별도 이슈로 나누고, 사용자 설정이 필요한 CloudKit 작업을 구분했다.
- CCRecorder 화면 서브뷰 구조와 `ConversationListScreen.Board`, `ConversationDetailScreen.Editor` 명명을 정리했다.
- SwiftData와 FocusState 환경을 포함한 UI 프리뷰 9곳을 추가하고 Simulator 빌드를 확인했다.
- 재생 시간 표시를 `PlaybackTimeFormatStyle`로 통합해 `mm:ss`, `HH:mm:ss`와 반올림 정책을 일관되게 만들었다.
- `marcorable-kit`의 SwiftUI 규칙을 보완하고 검증한 뒤 PR #3을 생성했다.
- JavaScript부터 Expo와 기기 기능 실험까지 이어지는 React Native 학습 로드맵을 작성했다.

### 진행 중

- `MainNavigationStack` 프리뷰 변경은 빌드 확인을 마쳤지만 아직 커밋하지 않았다.
- `marcorable-kit` 규칙 파일은 PR 병합 후 CCRecorder에 다시 동기화할 예정이다.

### 다음에 할 일

- `marcorable-kit` PR #3을 검토·병합한 뒤 CCRecorder에 최신 규칙을 동기화한다.
- CCRecorder의 남은 프리뷰 변경을 커밋하고 v1.3.0 리팩터링을 이어간다.
- React Native 로드맵의 JavaScript 기본 문법 단계부터 학습을 시작한다.

## 기록에서 배운 점

### [How to use Linear: Small teams](https://linear.app/docs/how-to-use-linear-small-teams)

- 소규모 팀의 Linear 사용법을 확인하기 위한 공식 문서 링크를 기록했다.
- Notion Record 본문은 비어 있어 문서의 세부 내용은 이번 TIL에 추정해 넣지 않았다.

### [Apple HIG — Layout](https://developer.apple.com/design/human-interface-guidelines/layout)

- 레이아웃은 정렬, 들여쓰기, 관련 항목의 그룹화와 점진적 공개를 통해 정보의 시각적 계층을 전달해야 한다.
- 기기 종류나 방향 자체보다 compact·regular 크기 등급을 기준으로 설계하고, 크기 등급이 바뀌어도 기능은 동일하게 유지해야 한다.
- Dynamic Type, 현지화, 좌우 방향, 리사이즈 가능한 창, 외부 디스플레이처럼 화면 크기 외의 변화도 적응형 레이아웃의 입력으로 봐야 한다.
- 다양한 크기 등급과 텍스트 크기에서 프리뷰하고 안전 영역과 일관된 간격을 함께 검증해야 한다.

### [Syncing model data across a person’s devices](https://developer.apple.com/documentation/swiftdata/syncing-model-data-across-a-persons-devices)

- SwiftData의 기기 간 동기화는 CloudKit을 기반으로 하며, 앱에 iCloud와 Background Modes capability를 추가하는 준비가 필요하다.
- 모델 스키마는 CloudKit 호환성을 만족해야 하고 개발 스키마 초기화 및 기존 CloudKit 컨테이너 연결 과정을 고려해야 한다.
- 이미 CloudKit을 직접 사용하는 앱이라면 SwiftData의 자동 동기화를 그대로 켜기보다 기존 구성과의 충돌 여부를 먼저 판단해야 한다.

### [React Native 학습 로드맵 — ReturnTheFavor 준비](https://app.notion.com/p/400d5c4871bd8193b012ca529cacf4f4)

- 학습 순서는 JavaScript, 비동기와 모듈, TypeScript, React, React Native·Expo, 기기 기능 실험으로 이어지며 앞 단계의 언어와 상태 관리 기반을 건너뛰지 않는다.
- 강의 시청 자체가 아니라 강의 없이 다시 구현하고 설명하며, 예제를 변형할 수 있는 상태를 완료 기준으로 삼는다.
- ReturnTheFavor 구현 전에 SQLite CRUD, 알림 예약·취소, 연락처 선택을 별도 Expo 프로젝트에서 독립적으로 검증한다.
- Swift·SwiftUI 경험과 대응 개념을 비교해 기록하면 새로운 생태계의 차이를 더 명확히 이해할 수 있다.
