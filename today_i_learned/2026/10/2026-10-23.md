# 2026-10-23

## 오늘의 기록

CCRecorder의 RecordScreen을 TCA Feature로 전환하고 Usecase 의존성, 비동기 Effect 취소 생명주기, 저장 정책을 TestStore로 검증한 PR #93을 병합했다. 후속 구조 검토에서는 TCA Navigation과 Tuist 기반 클린 아키텍처 모듈 구성을 조사하고, 실제 화면 전환을 옮긴 뒤 기존 MVVM 패키지를 제거하기로 했다.

`marcorable-kit`은 Swift와 SwiftUI 팩의 역할을 분리하고 GitHub·Orca 작업 절차를 보강했다. ReciteScripts에서는 공통 규칙 동기화, Flutter 양 플랫폼 검증 환경, 기술 전환 회고를 차례로 병합했으며 MVP 요구사항과 수용 기준도 문서화했다.

## 작업 기록

### 완료

- CCRecorder RecordScreen의 상태와 비동기 Effect를 TCA Feature로 옮기고 PR #93을 병합했다.
- Record·SaveConversation Usecase 의존성과 취소 생명주기, 저장 정책을 테스트로 검증했다.
- TCA Navigation과 Tuist 기반 클린 아키텍처 모듈 구성을 조사해 다음 구조 변경의 기준을 세웠다.
- `marcorable-kit`에서 Swift 팩을 가독성 중심으로 정리하고 SwiftUI 공통 규칙을 별도 팩으로 분리했다.
- GitHub·Orca 워크플로를 보강하고 `marcorable-mvvm`과 `marcorable-tca`의 동시 주입을 차단했다.
- Claude·Codex 주입, 팩 조합 생성, 멱등성과 전체 스킬 검증을 통과했다.
- ReciteScripts PR #52~#54를 병합해 공통 작업 규칙, Flutter 양 플랫폼 검증 환경, 기술 전환 회고를 반영했다.
- ReciteScripts 이슈 #13의 MVP 요구사항, 수용 기준, 예외와 범위 밖 항목을 문서화했다.
- 2026-10-23 Notion Daily Log를 생성하고 TODO·Record 공유 뷰의 날짜 필터를 설정했다.

### 진행 중
