# 2026-10-19

## 오늘의 기록

Claude와 Codex가 같은 규칙과 스킬을 사용할 수 있도록 `marcorable-kit`의 에이전트 팩 구조를 `agent-common/` 중심으로 정비했다. 공통 정본과 에이전트별 생성물을 분리하고, `sync.sh`가 각 에이전트의 감지 경로에 맞는 결과물을 만들도록 수정했다. 임시 Git 저장소를 이용한 동기화 검증은 아직 진행 중이다.

CCRecorder에서는 Domain·UI·Asset 구조 리팩터링 이슈 #76을 만들고, 기존 PR #75가 해당 이슈를 닫도록 연결했다. 작업의 목적과 완료 조건을 이슈로 명확히 남기면서 코드 변경과 프로젝트 계획을 추적할 수 있게 했다.

반복되는 기록 작업을 줄이기 위해 Claude·Codex 세션을 모아 Notion Daily Log의 Memo에 작성하는 개인 스킬 `daily-log-session-summary`를 만들었다. 또한 누락됐던 10월 16일 TIL과 10월 12~18일 주간 요약을 추가해 학습 기록을 보완했다.
