# 2026-10-26

## 오늘의 기록

ReciteScripts에서는 Android 온디바이스 STT의 기술 위험을 검증하고 앱 이름 `말또`, Cupertino 디자인 토큰, Flutter 공식 MVVM과 `drift + SQLite` 기반 구조를 차례로 확정했다. CCRecorder에서는 Domain Entity와 SwiftData 저장 구조를 단순화했지만, 서로 다른 `@Model`의 실제 클래스명이 모두 `Record`라 생기는 엔티티 충돌을 발견해 후속 수정이 필요하다.

ReturnTheFavor는 Expo·TypeScript·React Native·SQLite를 작은 화면 구현과 연결해 배우는 순서를 정리했다. 관련 공식 문서와 강의를 Record로 모으고 TypeScript의 정적·구조적 타입 체계를 먼저 학습했다.

## 작업 기록

### 완료

- ReciteScripts의 Android 온디바이스 STT 스파이크를 구현·검증하고 PR #59를 병합했다. 실제 한국어 전사 품질과 제조사별 차이는 #36 실기기 QA로 인계했다.
- 앱 이름 `말또`를 확정한 PR #60과 Flutter Cupertino 디자인 토큰 PR #61을 병합했다.
- Flutter 공식 MVVM 구조와 `drift + SQLite` 저장 방향을 반영한 PR #62를 병합했다.
- CCRecorder의 Note 표시 로직을 ViewModel로 옮기고, Conversation·Party의 Domain/저장 변환 구조를 정리했다.
- ReturnTheFavor에서 Expo부터 TypeScript, React Native, SQLite까지 이어지는 학습 순서를 정리했다.

### 진행 중

- ReciteScripts #21에서 MVP 전체 화면 목업, 오류 상태, 큰 글씨와 최소 터치 영역을 검토하고 있다.
- CCRecorder의 `Conversation.Record`와 `Party.Record`가 SwiftData 내부에서 같은 엔티티명으로 충돌하는 문제를 확인했다.

### 다음에 할 일

- CCRecorder의 실제 `@Model` 타입명을 고유하게 분리하고 Data 테스트와 앱 빌드를 다시 검증한다.
- ReciteScripts #21 목업을 마친 뒤 접근성 크기와 어절 상태 표현을 실제 화면에서 확인한다.
- TypeScript 기초를 작은 React Native 화면에 적용하고, 이후 SQLite 영속화로 확장한다.

## 기록에서 배운 점

### [TypeScript](https://www.typescriptlang.org/ko/docs/handbook/2/basic-types.html)

- TypeScript는 JavaScript 프로그램을 실행하기 전에 오류를 찾는 정적 타입 검사기이며, 타입 정보는 컴파일 뒤 지워진다.
- 클래스 선언의 이름보다 객체가 가진 프로퍼티 구조로 호환성을 판단하는 구조적 타입 체계를 사용한다.
- 명시적 타입과 엄격도 설정은 실행 전에 실패 가능성을 줄이고 개발 도구의 추론과 피드백을 강화한다.

### [Expo SQLite](https://docs.expo.dev/versions/latest/sdk/sqlite/)

- Expo의 SQLite 저장 기능을 학습 대상으로 기록했다.
- Record 본문은 비어 있어 API 사용법이나 구체적인 설계 판단은 이번 기록에 추정해 넣지 않았다.

### [Expo Tutorial](https://app.notion.com/p/405d5c4871bd80b783d8ca12940c7d26)

- React Native와 Expo 튜토리얼을 시작점으로 기록했다.
- 본문에는 주제만 있어 세부 학습 내용은 후속 기록에서 보완해야 한다.

### [React Native](https://reactnative.dev/)

- React Native 공식 문서를 학습 자료로 기록했다.
- Record 본문이 비어 있어 구체적인 API나 결론은 포함하지 않았다.

### [The Modular Architecture (TMA)](https://app.notion.com/p/405d5c4871bd804ab2bbd7f7ee496efb)

- Swift/iOS 모듈 구조를 검토할 자료로 기록했다.
- 원문 링크와 본문이 모두 비어 있어 제목 이상의 내용은 추정하지 않았다.

### [바닐라 JS로 크롬 앱 만들기](https://nomadcoders.co/javascript-for-beginners/lectures/1705)

- JavaScript 기초를 다지는 강의의 Introduction을 학습 대상으로 기록했다.
- 아직 세부 메모가 없어 구체적인 문법이나 구현 내용은 후속 학습 뒤 정리한다.
